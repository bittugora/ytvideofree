YouTube periodically answers datacenter/server requests with a bot check ("Sign in to confirm you're not a bot"). The app works around this by trying a sequence of player clients — the TV client first, which most reliably clears the challenge without an account or cookies. A JavaScript runtime and a cookies file are only needed as a last resort for the web client. This page shows whether this server has what it needs.
